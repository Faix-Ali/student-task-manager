# Student Task Management System

## Project Description
Student Task Manager is a web application designed to help students organize, track, and manage their daily academic tasks efficiently. This project was developed as a collaborative assignment to demonstrate Git and GitHub workflows, version control best practices, branch management, and team collaboration mechanics.

## Features
* **Add Tasks:** Create new tasks with custom titles and descriptions.
* **Complete Tasks:** Toggle completion status on active task items.
* **Delete Tasks:** Remove unwanted or finished tasks from the interface.
* **Task Search:** Dynamically search and filter task items by title keywords.
* **Responsive Layout:** Clean CSS styling tailored for desktop and mobile displays.

## Technologies
* **HTML5:** Markup structure.
* **CSS3:** Custom styles and card layouts.
* **JavaScript (ES6):** DOM manipulation, state filtering, and event handling.
* **Git & GitHub:** Distributed version control, PR reviews, and releases.

## Git Workflow
We followed a feature-branch workflow paired with GitHub Pull Requests and Code Reviews:
1. Initialize local repository and set up remote origin on GitHub.
2. Create dedicated feature branches for new user interface components and styles.
3. Commit incremental functional changes with descriptive messages.
4. Push feature branches to remote and open GitHub Pull Requests.
5. Perform peer code reviews, approve modifications, and merge into `main`.
6. Simulate and resolve merge conflicts collaboratively.
7. Tag stable milestones (`v1.0.0`) and publish GitHub Releases.

## Branches
* `main`: Stable production-ready code.
* `feature/task-form`: Form input structures for adding tasks.
* `feature/task-style`: Visual CSS enhancements and layout styling.
* `feature/task-search`: Search filtering functionality linked to GitHub Issues.
* `conflict-a` / `conflict-b`: Branches created to demonstrate merge conflict resolution.

## Git Commands Demonstrated
* `git init` - Initialize local repository.
* `git status` - Inspect working tree and staging state.
* `git add` - Stage file modifications.
* `git commit` - Commit staged changes to local history.
* `git log` - Review commit logs and history graphs (`--oneline --graph --all`).
* `git branch` & `git switch` - Create, list, and switch active branches.
* `git diff` - View unstaged/staged code modifications.
* `git fetch` & `git pull` - Synchronize local branch with remote repository.
* `git push` - Upload local branch commits and tags (`--tags`) to GitHub.
* `git merge` - Integrate feature branches and resolve conflict markers.
* `git stash` & `git stash pop` - Temporarily shelf and restore uncommitted changes.
* `git restore` - Discard working tree changes.
* `git reset` - Revert commits locally (`--soft`).
* `git revert` - Safely invert commit history without destructive rewriting.
* `git tag` - Tag stable release checkpoints (`v1.0.0`).

## GitHub Features Demonstrated
* **Public Repository:** Central hosting for project source code.
* **GitHub Issues:** Tracking bugs, layout fixes, and feature requests.
* **Pull Requests & Code Reviews:** Reviewing code lines, adding comments, and formal approvals.
* **Merge Conflict Handling:** Resolving remote branch overlap cleanly.
* **Linked Issues:** Automatically closing issues via PRs (`Closes #1`).
* **Tags & Releases:** Publishing version `v1.0.0` releases with changelogs.
* **Insights & Contributors Graph:** Verifying team commit metrics.
